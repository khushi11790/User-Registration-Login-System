# User Registration and Login System

A web-based User Registration and Login System developed using Java, JSP, Servlets, JDBC, and MySQL. The application allows users to register an account, securely log in, and access a home page after successful authentication.

## Features

- User Registration
- User Login Authentication
- Form validation
- Database connectivity using JDBC
- Dynamic web pages using JSP
- Session management
- User-friendly interface

## Technologies Used

- **Backend:** Java, Java Servlets
- **Frontend:** HTML, CSS, JSP
- **Database:** MySQL
- **Database Connectivity:** JDBC
- **Build Tool:** Maven
- **IDE:** IntelliJ IDEA
- **Server:** Apache Tomcat

## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/khushi11790/User-Registration-Login-System.git
```

2. Open the project in IntelliJ IDEA or another Java IDE.

3. Configure your MySQL database and update the database connection details in the Java source code.

4. Configure Apache Tomcat.

5. Build the project using Maven.

6. Deploy the application on Tomcat and open it in your browser.
